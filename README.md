# よけゲー

せまりくる図形を上下左右に動いてよける、1プレイ約1分のブラウザゲームです。

## 遊び方

- PC: 矢印キー または W / A / S / D キー
- スマホ: 画面のどこかに指を置き、なぞった方向へ移動(なぞる距離が大きいほど速い)
- 自機が動けるのは画面の下側(点線より下)です
- スペースキー、またはタップでスタート / リトライ
- P / Esc キー、または右上の Ⅱ ボタンで一時停止(タブを離れると自動で一時停止)
- M キー、または右上のスピーカーボタンで消音

## ルール

- 10秒ごとにレベルが上がり、新しい図形が登場します(ボール → トゲ → ヨコギリ → ゆらゆら → カベ → ツキアゲ → ブンレツ)
- ヨコギリは横から、ツキアゲは下から来ます。上下に動いてよけましょう
- 障害物のすぐ横をかすめると「ニアミス」ボーナス。続けるとコンボ倍率が上がります
- コインで +50 点、シールドで1回だけ被弾を防げます
- ゲームオーバー時にスコアに応じた S / A / B / C の評価が出ます

## 構成

ライブラリを使わない静的ファイルのみです(`index.html` / `style.css` / `game.js`)。
ハイスコアはブラウザの localStorage に保存します。

難易度などの調整値は `game.js` 先頭の `TUNE` にまとめています。
