# よけゲー セキュリティレビュー

- 実施日: 2026-10-12
- 対象: masa-dev312/dodge-game の main(index.html / style.css / game.js / README.md)と、GitHub Pages での公開構成
- 実施者: Claude(AIによるコードレビュー。人間のセキュリティ専門家による監査ではありません)

## まとめ

重大な問題は見つかりませんでした。サーバー、ログイン、外部通信、外部ライブラリがない静的ゲームなので、攻撃される余地はもともと小さい構成です。念のための強化を2点入れました(下の「対応したこと」)。

## 確認した項目と結果

| 項目 | 結果 | 根拠 |
|---|---|---|
| HTMLの差し込み(XSS) | 問題なし | `innerHTML` / `document.write` / `eval` などの危険な書き方は使っていません。画面の文字はすべて Canvas に描画しており、ボタンの文字は `textContent` で設定しています |
| 外部への通信 | なし | `fetch` / `XMLHttpRequest` / `WebSocket` などは使っていません |
| 外部スクリプトや外部ライブラリ | なし | 読み込むのは同じサイトの `game.js` と `style.css` だけです。依存パッケージもありません |
| 個人情報の扱い | なし | 保存するのはハイスコアと消音設定だけで、その端末のブラウザ内(localStorage)にとどまります |
| 秘密情報の混入 | なし | リポジトリのファイルとコミット履歴に、パスワードやAPIキーなどは含まれていません |
| 保存値の書き換え | 影響は小さい | 利用者が自分のブラウザで値を書き換えても、変わるのはその人の画面のハイスコア表示だけです。不正な値は無視するようにしました |
| 通信の暗号化 | 問題なし | `*.github.io` のサイトは GitHub が HTTPS で配信します |

## 対応したこと(プルリクエスト #3 で反映済み)

1. **Content Security Policy(CSP)を追加**: このサイト自身のファイル以外のスクリプトや通信を、ブラウザが拒否するようにしました。将来うっかり外部の何かを読み込む変更が入っても、被害が広がりにくくなります。
2. **ハイスコアの読み込みを検証**: 負の数、極端に大きい数、数字以外が保存されていた場合は 0 として扱います。

## 対応していないこと・制約

- **クリックジャッキング対策(他サイトへの埋め込み禁止)**: GitHub Pages では応答ヘッダーを設定できず、`<meta>` タグでは `frame-ancestors` を指定できません。ただし、このゲームには埋め込まれて困る操作(購入、ログインなど)がないため、実害はないと判断しました。
- **ランキングなどのオンライン機能**: 企画書で v1.1 以降の候補にしているオンラインランキングを作る場合は、サーバーとスコアの不正対策が必要になります。そのときに改めてレビューが必要です。

## 推奨(任意)

- GitHub のリポジトリ設定で `main` ブランチの保護(直接プッシュの禁止など)を有効にすると、意図しない変更が公開されにくくなります。
- 公開前に人間の専門家による監査が必要な場合(業務での利用など)は、別途依頼してください。
