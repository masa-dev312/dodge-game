## コンセプト

せまりくる図形を **撃って壊しながら** よけつづける、1プレイ約1分のブラウザゲーム。
よけゲーの「よける気持ちよさ」は残し、「壊す気持ちよさ」と「壊せないものをよける判断」を足します。

## ルール

- 自機は弾を **自動で** 撃ちつづける。プレイヤーは移動だけに集中する
- 図形ごとに **HP(弾を何発当てると壊れるか)** がある。壊すと撃破点が入る
- **カベは壊せない**。弾も止められるので、すき間を通ってよける。すき間の **ふち近くを撃つと、すき間が広がる**
- **ブンレツ** は壊すと2つの小さなボールに割れて左右に飛び、**3方向アイテムを落とす**
- アイテム **3方向**: 取ると6秒間、弾が3方向に広がる
- コイン、シールド、ニアミス、コンボ、レベル(10秒ごと)、S/A/B/C 評価はよけゲーと同じ仕組み
- ハイスコアはよけゲーとは別に保存する

### 壊す楽しさを増やす仕組み(2026-10-12 追加)

| 仕組み | 内容 | ねらい |
|---|---|---|
| 撃破チェイン | 1.2秒以内に続けて壊すと倍率が上がる(最大 x5)。撃破点に倍率がかかる | 壊しつづける爽快感。止まらず撃てる位置を探す動機になる |
| 誘爆 | 壊れた図形のまわり(46px)にいる図形に1ダメージ。壊れたらさらに誘爆する | 密集を一気に崩す気持ちよさ。障害物が多いほどチャンスになる |
| ギリギリ撃破 | 自機から 110px 以内で壊すと点が2倍 | 近づく危険と点数の交換。よけゲーの「ニアミス」と同じ考え方 |
| 落とし物 | 壊すと 12% でコインを落とす。ブンレツは必ず3方向を落とす | 固い図形を狙う理由を作る |

## 検討した選択肢

### 撃ち方: 自動連射 と 手動(ボタン)

| | 自動連射(採用) | 手動で撃つ |
|---|---|---|
| スマホ操作 | 今の「指でなぞる」操作のまま遊べる | 撃つボタンが必要。片手で移動と発射を同時にするのは難しい |
| 遊びの中心 | どこに位置取りするか | いつ撃つか |
| よけゲーとの近さ | 操作が同じなので移行しやすい | 操作が増える |

スマホでもそのまま遊べることを優先して、自動連射にしました。

### カベ: 壊せる と 壊せない

| | 壊せない(採用) | 壊せる |
|---|---|---|
| よける理由 | 撃っても消えないものが残るので、よける判断が必要 | 全部撃てば済むので、よける場面が減る |
| 見た目の分かりやすさ | 図鑑に「壊せない」と表示 | 特に説明不要 |

「よけゲーがベース」であることを残すため、カベは壊せないままにしました。

### 難しさの調整

最初の版(プルリクエスト #7)を遊んだ感想は「カベが難しい」「壊せるぶん全体が易しい」でした。2026-10-12 に次のように直しました。

| 項目 | 最初の版 | 今 | ねらい |
|---|---|---|---|
| カベのすき間 | 90px | 120px | カベを易しく |
| カベどうしの間 | 制限なし | 最低4秒 | 連続したカベをなくす |
| カベの直後 | すぐ次が出る | 0.6秒は他の障害物を出さない | すき間へ向かう余裕を作る |
| すき間のふちを撃つ | なし | 1発ごとに 6px 広がる(最大 200px) | カベにも撃つ意味を持たせる |
| 出現間隔(初期値/最小) | 0.75 / 0.28秒 | 0.55 / 0.2秒 | 全体を難しく |
| 落下速度(初期値/1秒ごとの増加) | 160 / 4 | 175 / 5 | 全体を難しく |
| 弾を撃つ間隔 | 0.16秒 | 0.22秒 | 壊しすぎを防ぐ |
| 3方向(続く秒数/出現確率) | 8秒 / 4% | 6秒 / 2%(ブンレツを壊すと必ず出る) | 壊しすぎを防ぐ |
| HP | ゆらゆら2、ブンレツ4 | ゆらゆら3、ブンレツ6、大きいボール2 | 壊しすぎを防ぐ |

#### 自動プレイでの比較

無敵にした自動プレイ(0.7秒先の障害物を見てよける簡単なプログラム)で60秒遊ばせ、「ぶつかりそうになった回数」を数えました。1案につき6回ずつです。

| 案 | 平均 | 6回の内訳 | うちカベ |
|---|---|---|---|
| 最初の版 | 4.3回 | 5, 8, 3, 1, 2, 7 | 2回 |
| 調整案1(カベの調整、新しい仕組み、出現間隔 0.6秒、連射 0.2秒) | 4.3回 | 5, 3, 5, 2, 6, 5 | 2回 |
| 調整案2(案1 + 落下を速く、連射 0.22秒) | 4.8回 | 1, 3, 5, 6, 4, 10 | 0回 |
| **調整案3(案2 + 出現間隔 0.55秒)、採用** | **6.0回** | 2, 10, 4, 7, 5, 8 | **0回** |

調整案3がいちばん「全体は難しく、カベは易しく」に近かったので採用しました。
ただし回ごとのばらつきが大きく、6回ずつでは差がはっきりしたとまでは言えません。自動プレイは人の遊び方とは違うので、実際に遊んだ感想で引き続き調整します。

## 仮の値

HP、撃破点、評価のしきい値(S 3500 / A 2000 / B 1000。撃破チェインで点が増えたため上げた。自動プレイで無敵のまま60秒遊ばせると 3800〜4800 点だった)は、試しに遊んだうえで決めた **仮の値** です。
実際に遊んでみて、`src/shooter/game.ts` 先頭の `TUNE` で調整します。
