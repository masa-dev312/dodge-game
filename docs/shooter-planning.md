## コンセプト

せまりくる図形を **撃って壊しながら** よけつづける、1プレイ約1分のブラウザゲーム。
よけゲーの「よける気持ちよさ」は残し、「壊す気持ちよさ」と「壊せないものをよける判断」を足します。

## ルール

- 自機は弾を **自動で** 撃ちつづける。プレイヤーは移動だけに集中する
- 図形ごとに **HP(弾を何発当てると壊れるか)** がある。壊すと撃破点が入る
- **カベは壊せない**。弾も止められるので、すき間を通ってよける
- **ブンレツ** は壊すと2つの小さなボールに割れて左右に飛ぶ
- 新しいアイテム **3方向**: 取ると8秒間、弾が3方向に広がる
- コイン、シールド、ニアミス、コンボ、レベル(10秒ごと)、S/A/B/C 評価はよけゲーと同じ仕組み
- ハイスコアはよけゲーとは別に保存する

## 検討した選択肢

### 撃ち方: 自動連射 と 手動(ボタン)

| | 自動連射(採用) | 手動で撃つ |
|---|---|---|
| スマホ操作 | 今の「指でなぞる」操作のまま遊べる | 撃つボタンが必要。片手で移動と発射を同時にするのは難しい |
| 遊びの中心 | どこに位置取りするか | いつ撃つか |
| よけゲーとの近さ | 操作が同じなので移行しやすい | 操作が増える |

スマホでもそのまま遊べることを優先して、自動連射にしました。

### カベ: 壊せる と 壊せない

| | 壊せない(採用) | 壊せる |
|---|---|---|
| よける理由 | 撃っても消えないものが残るので、よける判断が必要 | 全部撃てば済むので、よける場面が減る |
| 見た目の分かりやすさ | 図鑑に「壊せない」と表示 | 特に説明不要 |

「よけゲーがベース」であることを残すため、カベは壊せないままにしました。

### 難しさの調整

撃って減らせるぶん、よけゲーより障害物を多めに出します(出現間隔の初期値 0.9秒 → 0.75秒)。
また、撃破点が入るので、生き残っているだけでもらえる点は 1秒 10点 → 5点 に下げました。

## 仮の値

HP、撃破点、評価のしきい値(S 3000 / A 1800 / B 900)は、試しに遊んだうえで決めた **仮の値** です。
実際に遊んでみて、`shooter/game.js` 先頭の `TUNE` で調整します。
