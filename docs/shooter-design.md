# よけうち 設計書

- 作成日: 2026-10-12
- 対象: `shooter/` フォルダ

## ファイル構成

```
shooter/
  index.html   画面の骨組み。タイトル「よけうち」。CSP はよけゲーと同じ
  style.css    よけゲーと同じ内容のコピー
  game.js      ルール、当たり判定、2D描画、UI(よけゲーの game.js をもとに改造)
  render3d.js  3D描画(よけゲーの render3d.js をもとに改造)
vendor/        Three.js r160。よけゲーと共有し、shooter/render3d.js から ../vendor/ で読み込む
```

よけゲーのファイルとは独立したコピーです。片方を直しても、もう片方には影響しません。
コードの重複は増えますが、完成したよけゲーを壊さないことを優先しました。

## よけゲーからの主な変更点

### 弾(game.js)

- `fire(dt)`: `TUNE.fireInterval`(0.16秒)ごとに自機の上から弾を出す。3方向の間は ±0.22 ラジアン(約 ±12.6度)の2発を足す
- `moveBullets(dt)`: 弾を動かし、当たりを調べる。弾は速い(720 px/秒)ので、1フレームで障害物を飛び越えないように **8px ずつ区切って** 動かしながら判定する
- `bulletHit(b, dead, addBorn)`: 1発の弾が何かに当たったかを調べる
  - コイン、シールド、3方向アイテムは素通りする
  - カベはすき間以外で弾を止める(壊れない)
  - それ以外は HP を1減らし、0 になったら `destroy(o)` を呼ぶ
- `destroy(o, dead, cause)`: 撃破数、撃破チェイン、点(チェイン倍率、ギリギリ撃破の2倍)を加え、破片、点数表示、効果音、画面ゆれを出す。ブンレツなら小さなボール2つと3方向アイテムを、それ以外は 12% でコインを返す。最後に誘爆として、半径 `blastR` 内の図形に1ダメージを与え、壊れたものは同じ関数で続けて処理する(`cause` は 'shot' か 'blast')
- カベ: 弾がすき間のふちから 40px 以内に当たると、そのふちを `wallWiden` だけ外へ広げる。`spawn()` はカベを `wallEvery` 秒より短い間隔で出さず、カベを出した直後 `wallClear` 秒は何も出さない

更新の順番は `moveThings → fire → moveBullets → collide`(自機との当たり判定)です。

### 3D描画(render3d.js)

- 弾: 細長い球を最大120個まで使い回す(毎フレーム作り直さない)。進む向きに合わせて回転する
- 3方向アイテム: 十二面体。オレンジ色で回転する
- 弾が当たった図形は、0.08秒だけ少し大きく表示する
- WebGL が使えないときは、よけゲーと同じく2D描画(弾は細長い楕円、3方向アイテムは星形)に戻る

### 保存する値

| キー | 内容 |
|---|---|
| `shoot.best` | よけうちのハイスコア |
| `shoot.muted` | よけうちの消音設定 |

よけゲーの `dodge.best` / `dodge.muted` とは別のキーなので、互いのハイスコアを上書きしません。

## 調整値(TUNE の追加・変更分)

| 項目 | 値 | 意味 |
|---|---|---|
| `baseFall` / `fallGrowth` | 175 / 5 | 落下速度の初期値と1秒ごとの増加。よけゲーは 160 / 4 |
| `baseInterval` / `minInterval` | 0.55 / 0.2 | 出現間隔の初期値と最小値(秒)。よけゲーは 0.9 / 0.28 |
| `pointsPerSecond` | 5 | 1秒ごとの点。よけゲーは 10 |
| `fireInterval` | 0.22 | 弾を撃つ間隔(秒) |
| `bulletSpeed` / `bulletR` | 720 / 4 | 弾の速さ(px/秒)と当たり判定の半径(px) |
| `powerChance` / `powerTime` | 0.02 / 6 | 3方向アイテムの出現確率と続く秒数 |
| `hp` / `bigCircleR` / `killPoints` | 企画書の表のとおり | 図形ごとの HP、HP 2 になるボールの半径、撃破点 |
| `chainWindow` / `maxChain` | 1.2 / 5 | 撃破チェインが続く秒数と倍率の上限 |
| `blastR` | 46 | 誘爆の半径(px) |
| `closeDist` | 110 | ギリギリ撃破になる距離(px) |
| `dropCoin` | 0.12 | 壊したときにコインを落とす確率 |
| `wallGap` / `wallMaxGap` / `wallWiden` | 120 / 200 / 6 | カベのすき間の幅、広げられる上限、1発で広がる量(px) |
| `wallEvery` / `wallClear` | 4 / 0.6 | カベどうしの最低間隔、カベ直後に何も出さない秒数 |
| `ranks` | S 3500 / A 2000 / B 1000 / C 0 | 評価のしきい値(仮) |

## 動作確認

ローカルのサーバーとヘッドレスブラウザ(Chromium)で次を確かめました。

- 3D表示で起動し、エラーが出ない
- 弾が図形に当たり、撃破数と点が増える
- ブンレツを壊すと、小さなボール2つに割れる
- カベのすき間以外では、弾がカベの向こうへ抜けない
- ハイスコアが `shoot.best` に保存され、よけゲーの `dodge.best` は変わらない
- 並んだ3つのボールの真ん中を撃つと、誘爆で3つとも壊れ、撃破チェインが x3 になる
- ブンレツを壊すと、ボール2つと3方向アイテムが出る
- カベのすき間のふちを撃つと、すき間が広がる

実機のスマホでの操作感は、この環境からは確かめられていません。

## セキュリティ

よけゲーと同じ構成(静的ファイルのみ、外部通信なし、CSP `script-src 'self'`)です。
新しく外部から読み込むものはありません。Three.js は既存の `vendor/` のファイルを使います。
